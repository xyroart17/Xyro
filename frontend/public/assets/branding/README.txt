XYRO LOGO PACK

Included files:
- XYRO_red_vector.svg / XYRO_black_vector.svg / XYRO_white_vector.svg: scalable vector silhouette. Open in Illustrator, Photoshop, Affinity Designer, Inkscape, or import into Blender. Edit the fill attribute to change color.
- XYRO_*_transparent_4096.png: 4096 x 4096 transparent PNGs for logo placement.
- XYRO_*_watermark_28pct_4096.png: low-opacity black/white watermark overlays.
- XYRO_original_red_4096.png: upscaled original red rendering with its shading.
- Preview_white.jpg: quick preview.

Recommended use:
- Artwork watermark: black or white 28% watermark PNG, then adjust opacity to suit the artwork.
- Logo: solid red/black/white transparent PNG or SVG.
- For tiny placements, test legibility at actual size.

Note: The SVG is an automatically traced vector silhouette of the generated artwork, not a hand-redrawn typographic master. For a final commercial identity, manually refine the letter paths and intersections in a vector editor.
